# UGX Loan Amortization Calculator

A Python script that calculates monthly EMI and generates a full loan repayment schedule for loans in Ugandan Shillings (UGX).

### **Features**
- Calculates Equated Monthly Installment (EMI) for any loan amount, rate, and term
- Generates month-by-month breakdown: Principal, Interest, Balance
- Exports full schedule to `loan_schedule.xlsx`

### **How to Run**
1. Install pandas: `pip install pandas openpyxl`
2. Run the script: `python loan_calculator.py`
3. Check `loan_schedule.xlsx` for your repayment table

### **Example Used**
5,000,000 UGX loan at 20% annual interest for 2 years

### **Skills Shown**
Python, pandas, Financial Math, Excel Automation
